Швидкий, легкий і гарний текстовий редактор для Windows, написаний на C# з використанням Windows Forms.
Він замінює класичний Блокнот власним темним інтерфейсом, вбудованою панеллю пошуку й заміни,
режимом «Дзен» без відволікань та автоматичним відновленням тексту після збою — і при цьому залишається
простим редактором лише для звичайного тексту.

## Можливості

- **Власний безрамковий інтерфейс** зі своїм заголовком, меню та рядком стану
- **Теми оформлення**: кілька готових тем, акцентні кольори, кольори тексту та вибір власного кольору тексту
- **Режим «Дзен»** (`F11`): усе зникає, крім тексту; повернутися можна клавішею `Esc`
- **Панель пошуку й заміни**: пошук під час введення, лічильник збігів, облік регістру,
  «знайти далі / попереднє», пошук по колу, замінити одне / замінити все (скасовується через `Ctrl+Z`)
- **Перехід до рядка**
- **Дублювання рядка**
- **Розумне визначення кодування**: UTF-8 (з BOM і без), UTF-16 LE/BE,
  а для старих кириличних файлів — автоматичний перехід на Windows-1251
- **Відновлення після збою**: резервна копія зберігається кожні 30 секунд,
  після аварійного завершення редактор пропонує повернути незбережений текст
- **Рядок стану**: рядок і стовпець, довжина виділення, кількість слів і символів, масштаб, кодування
- **Вставка лише тексту**: форматування при вставці прибирається, комбінації розширеного тексту (`Ctrl+B/I/U` тощо) вимкнено
- **Перетягування файлів** у вікно, а також відкриття через «Відкрити за допомогою…» чи командний рядок
- **Друк** з параметрами сторінки та багатосторінковим виведенням
- **Масштаб**, перенесення за словами та вибір шрифту
- **Запам'ятовує налаштування**: розмір вікна, тему, шрифт, масштаб, перенесення за словами та видимість рядка стану
- Захист від втрати змін під час відкриття, створення нового документа та закриття

## Вимоги

- Windows 10 або Windows 11
- [.NET 10.0 SDK](https://dotnet.microsoft.com/download) або новіший (для збирання з вихідного коду)

## Початок роботи

### Збирання з вихідного коду

```bash
git clone https://github.com/CapitanSashko/Text-Editor.git
cd Text-Editor
dotnet build -c Release
```

Запуск:

```bash
dotnet run -c Release
```

### Автономна збірка

```bash
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

Результат буде в папці `publish`. Щоб програма працювала без встановленого .NET, використайте
`--self-contained true` (файли будуть більшими за розміром).

### Відкриття файлу з командного рядка

```bash
NotePad.exe "C:\path\to\file.txt"
```

## Використання

| Дія | Клавіші |
| --- | --- |
| Увімкнути / вимкнути режим «Дзен» | `F11` |
| Закрити панель пошуку / вийти з режиму «Дзен» | `Esc` |
| Вставити як звичайний текст | `Ctrl+V` |
| Скасувати дію | `Ctrl+Z` |

Решта команд доступна в меню, де біля кожної вказано комбінацію клавіш.

## Де зберігаються налаштування

Налаштування та резервні копії лежать у `%LOCALAPPDATA%\NotePadPro`:

- `settings.ini` — тема, шрифт, масштаб, розмір вікна
- `recovery_<id>.txt` — резервна копія незбереженого тексту (видаляється при звичайному закритті)
